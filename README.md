# Laboratory-work-3.3-v24

3.3 Обработка массивов переменной длины

Дан двумерный массив A, состоящий из n строк и n столбцов и/или
одномерные массивы из n элементов каждый. Составить программу для
получения и вывода указанных в условии результатов и самих массивов, если
изменялись какие-либо их элементы. Необходим цикл для ввода данных.
Алгоритм решения любой задачи может быть составлен с использованием
единственного двукратного цикла. Предусмотреть случай, когда искомых
элементов в исходном массиве нет.

24. Найти общую сумму элементов тех столбцов двумерного массива, сумма элементов в каждом из которых положительна, и сумму элементов главной диагонали.
